# conky-bluetooth-monitor

Deskripsi: Monitor status Bluetooth sederhana.

Dependencies:
- `conky`
- `bluetoothctl` (umumnya tersedia pada sistem dengan BlueZ)

Usage:

```bash
conky -c ~/.config/conky/conf/conky-bluetooth-monitor/conky-bluetooth-monitor &
```

Catatan: pastikan service BlueZ aktif jika ingin menampilkan perangkat.
