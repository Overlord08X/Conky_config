# conky-exploded-view

Deskripsi: Konfigurasi dengan latar gambar `bg.png` / `bg.xcf` untuk tampilan eksploded view.

Dependencies:
- `conky`
- (opsional) `gimp` atau editor gambar jika ingin memodifikasi `bg.xcf`

Usage:

```bash
conky -c ~/.config/conky/conf/conky-exploded-view/conky-exploded-view &
```
