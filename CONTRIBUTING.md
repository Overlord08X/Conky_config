# Contributing

Terima kasih sudah tertarik berkontribusi ke proyek Conky_config! Berikut beberapa petunjuk singkat untuk membantu proses kontribusi berjalan lancar.

1. Lapor bug atau minta fitur
- Buat issue baru di tab *Issues* dengan judul yang jelas dan langkah untuk mereproduksi (jika bug).

2. Mengirim Pull Request
- Fork repository ini, buat branch fitur/bugfix di fork Anda: `git checkout -b fix/some-thing`.
- Commit perubahan Anda secara terpisah dengan pesan yang jelas, lalu push ke fork.
- Buka Pull Request ke branch `00_main` di repo ini. Jelaskan perubahan dan alasan perubahan.

3. Gaya kode & kualitas
- Gunakan penamaan file yang deskriptif dan tambahkan komentar kecil jika perlu.
- Untuk skrip bash: hindari penggunaan hard-coded paths; gunakan variabel di bagian atas jika perlu.

4. Testing
- Jika Anda menambahkan skrip baru, sertakan langkah singkat bagaimana menguji skrip tersebut di `README.md` folder terkait.

5. Lisensi
- Semua kontribusi akan dianggap berada di bawah lisensi MIT dari proyek ini.

Terima kasih — setiap kontribusi kecil pun sangat membantu!
